# Работающий пилот атласа

Открыть `site/dist/index.html` в браузере или запустить `Открыть атлас.cmd`. Сайт работает без установки библиотек и без доступа в интернет. SQLite остаётся основным источником данных; `site/dist/data.js` — его проекция для чтения.

## Наполнение

- Проверенный и контекстно прочитанный слой охватывает 407 произведений из 413 записей реестра.
- В атласе 1131 редакторская карточка. Остаточные карточки сырого автоматического выделения удаляются после склейки подтверждённых совпадений и на сайт не попадают.
- Полный журнал последней чистки находится в `AUTOMATIC_NAME_AUDIT.md`.
- 322 пары «персонаж — другой текст» найдены по имени во всём каноническом корпусе. Они **кандидаты**, а не подтверждённые Appearance. Для Сандро таких текстов 23.
- В разобранных текстах 4177 mentions: 3815 имеют решения об идентичности, 362 оставлены неразрешёнными. Это не полный подсчёт всех упоминаний: местоименная кореференция не извлекается исчерпывающе.
- 2991 цитируемый фрагмент. Точность цитаты и диапазона символов проверяется программно.

Оценки роли главный / второстепенный / эпизод / упоминание — редакционные. Поле confidence описывает явность основания в тексте. Отдельное поле perspective/status различает рассказ повествователя, сообщение героя и опровергнутое заявление.

## Что можно посмотреть

Переключать центр графа; искать по имени и прозвищу; открывать состав произведений; читать цитаты; смотреть семьи и условную схему мест; переходить от подтверждённых появлений к поисковым кандидатам по всему десятитомнику. Реестр всех 413 канонических записей доступен в разделе произведений.

Схема мест намеренно не использует выдуманные географические координаты. Режим без спойлеров отложен. Сайт пока предназначен для чтения: редактора базы и автоматического LLM-запуска на всём корпусе нет.

## Важные решения пилота

- Сандро и Щащико — земляки и дальние родственники; конкретное заявление о двоюродном родстве опровергнуто и не попадает в семейное дерево без установленной линии родства.
- Степан Тимофеевич, называющий себя Лениным, и исторический Ленин — разные Person. Поиск «Ленин» показывает обоих.
- Инна, которую Степан называет Инессой, и Инесса Арманд — разные Person.
- Обращение девочки «Дедушка Ленин» не становится генеалогической связью.
- Отец Сандро переименован в Хабуга только после прямого именования в тексте. Махаз и Иса — два разных брата Сандро. Тётя Маша подтверждена как жена Махаза, а её дочери связаны с ветвью Тали.
- Мул Арапка и осёл Арапка — две разные Person с видом `animal`. Совпадающее имя сначала даёт неоднозначный Mention; решения записаны по контексту каждого вхождения.
- Катрин («Катя») из фронтового рассказа Кемала и тётя Катя, жена Сандро, — разные Person. Совпадающая форма «Катя» в девятом тексте сначала хранит обоих кандидатов и только затем разрешается по абзацу.
- Гибель Адамыра от руки Хазарата не превращена в прямой факт: связь хранится как `strongly_implied`, `reported` и снабжена пояснением, что очевидца нет.
- Безымянная дочь Сандро в городской сцене не объединена с Тали: возможное тождество сохранено как открытый вопрос.
- История женитьбы связывает Катю с Асланом, Шазиной и Теймыром. Сообщение Аслана о бабушке Кати хранится с perspective/status как рассказ героя, хотя родственная линия отображается в отдельной семейной схеме.
- Рассказчики восьми текстов объединены как strongly_implied по общему герою, семейной памяти и продолжающимся отношениям, без автоматического отождествления с реальным автором. Мул-рассказчик с ними не объединён.

## Обновление

```powershell
python build_pilot.py
python bulk_extract.py
python deep_read.py
python apply_context_reading.py
python apply_stateful_reading.py
python reconcile_people.py
python prune_automatic_candidates.py
python prepare_review_queue.py
python verify_pilot.py
python verify_review_queue.py
python verify_site.py
python quality_report.py
```

Или выполнить всю последовательность одной командой: `python refresh_pilot.py`.

`pilot_seed.py` содержит результаты чтения ассистентом: персонажей, контекстные привязки, связи и места. Это воспроизводимый пилот, а не обещание универсального автоматического извлечения. `build_pilot.py` сначала создаёт Mention, затем отдельно записывает MentionResolution. После сбора появлений собирает карточки и экспорт сайта. Сырой набор извлечений и его происхождение сохранены в JSON-поле ExtractionRun.

Повторный запуск пересобирает производные таблицы пилота. Ручные исправления нужно вносить в `pilot_seed.py`, иначе они будут заменены при следующей сборке. Корпус, исходные фрагменты inventory и канонический реестр не удаляются. Paragraph-фрагменты пилота добавлены в TextFragment с префиксом `para_`; WorkFragment связывает их с произведением.

Пакет «Кутеж трех князей в зеленом дворике», «История молельного дерева» и весь доступный цикл «Детство Чика» включены в проверенный пилот. `bulk_extract.py` создаёт временный широкий слой кандидатов; после склейки подтверждённых имён `prune_automatic_candidates.py` удаляет остаточные автоматические карточки. Главные проверки: не перепутать людей, сохранить точный источник, не превратить рассказ персонажа в объективный факт.
